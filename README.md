# luram-offline

Новый офлайн-мессенджер для сторонников концепции "недомессенджера" Luram. Пародийный веб-проект, высмеивающий современные тренды в сфере приватности и мессенджеров.

## Описание проекта

>[!NOTE]
>  Этот проект носит исключительно развлекательный и пародийный характер. Все упоминания других сервисов используются только в юмористических целях.

Наконец-то появился мессенджер, который решил главную проблему всех существующих платформ: утечки данных. 

В Luram Offline твои данные никуда не уходят — потому что уходить им просто некуда. Никаких серверов, никаких баз данных, никаких обещаний "заботы о приватности". Даже злоумышленники бессильны: что им делать с чатом, в котором вы общаетесь только сами с собой?

*Функция "clearest" для удаления сообщений? А нет, это скам, вы повелись.*

Добро пожаловать в самый честный, надёжный и лучший мессенджер в мире. Здесь вы одновременно и пользователь, и собеседник, и администратор.

## Стек технологий
- **HTML5** — базовая структура интерфейса чата
- **CSS3** — стилизация под современный мессенджер
- **JavaScript (ES6+)** — имитация отправки сообщений и локальная логика интерфейса (без сохранения данных)

---

## Запуск локально

Проект является полностью статическим и работает исключительно на стороне клиента. Никакие данные не отправляются на сервер.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Kievsky332/luram-offline.git
   ```
2. Перейдите в папку проекта:
  ```bash
  cd luram-offline
  ```
3. Откройте файл index.html двойным кликом в любом современном браузере.
---
# Структура проекта
luram-offline/
